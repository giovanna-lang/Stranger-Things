# Projeto 'Stranger Things fandom'

Projeto realizado para finalização do módulo 'Desenvolvimento Wed' do curso de _Informática_ da Microcamp Barueri.

O projeto teve por finalidade aplicar o que aprendi de HTML5 e CSS no módulo.
Foram utilizados:

- Tags 
- Imagens
- Fonte
- Paleta de cores
- Conteúdo do tema
- Tamanho 

## Escolha do tema

O tema escolhido foi Stranger Things por ser minha série preferida desde 2019 quando esperava o lançamento da terceira temporada.
Como a série terminou, quis explicar o porquê gosto tanto de Stranger Things apesar do final.

## Escolha do Layout (Fonte e Paleta de cores)

As cores escolhidas foram selecionadas do site _color hunt_. Escolhi essa paleta porque me lembram os anos 80, cores coloridas. 
São cores bem vivas que representam aquela época.

As fontes também foram com a mesma intenção, já que é uma série que se passa nos anos 80. Trazendo esse lado mais vintage!
